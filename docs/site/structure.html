CI, containers and editor tooling

FilePurpose
.github/workflows/api-tests.ymlThe pipeline: cheap checks first, then the suite split across four shards, then a job that merges the shard reports into one readable result — plus an offline contract job and a documentation build.
.vscode/extensions.jsonRecommended extensions, offered to anybody who opens the repository.
.vscode/launch.jsonTwo debug configurations: the current spec with breakpoints, and the whole suite serially.
.vscode/settings.jsonShared editor behaviour: format on save, ESLint autofix, the workspace TypeScript version, and hiding generated folders from search.
docker-compose.ymlTwo ready-made containerised runs: the full suite against a real environment, and the contract suite against the built-in stub server with no network at all.
DockerfileBuilds the image the suite runs in, so a local run and a CI run execute against the same runtime rather than two similar ones.
MakefileDiscoverable shortcuts.

FilePurpose

scripts/docs/build-docs.mjsAssembles the site.

scripts/docs/docs.cssThe stylesheet for the local site and the print sheet.

scripts/docs/render.mjsTurns content blocks and extracted API entries into HTML.

Authentication (src/auth)

FilePurpose
src/auth/hmac.auth.tsHMAC request signing, for payment, banking and webhook APIs that require each request to carry a signature over its own method, path, timestamp and body.
src/auth/index.tsBarrel for the authentication layer.
src/auth/jwt.tsJWT inspection — decoding only.
src/auth/oauth2.auth.tsOAuth 2.0 token acquisition: client credentials, resource-owner password, and refresh.
src/auth/session.auth.tsCookie-session authentication: logs in once, captures the session cookie, saves it under storage/, and replays it on later runs.
src/auth/static.auth.tsThe four credential schemes that need no network call: NoAuth, BasicAuth, BearerAuth and ApiKeyAuth.
src/auth/token.store.tsCaches access tokens, with an expiry skew, and optionally persists them to a file so separate worker processes can share one.

Contracts (src/contracts)

FilePurpose
src/contracts/index.tsBarrel for the contract layer.
src/contracts/json-schema.tsJSON Schema validation via Ajv, for schemas the team was *given* rather than wrote — an OpenAPI document, a partner's published contract, a schema from another repository.
src/contracts/openapi.tsValidates responses against an OpenAPI document: finds the operation for a method and path, resolves local $refs, picks the schema for the status, and hands it to Ajv.
src/contracts/schema.registry.tsMaps method + path pattern + status to a schema.
src/contracts/schemas.tsReusable schema building blocks: identifiers, timestamps, money, pagination envelopes, and the standard error shapes.

Utilities (src/utils)

FilePurpose
src/utils/cleanup.registry.tsTracks resources a test created so they can be removed afterwards.
src/utils/data.utils.tsTest data: seeded Faker, factories, unique identifiers, and curated collections of adversarial strings, numbers and dates.
src/utils/diff.utils.tsStructural comparison: a value diff with ignorable fields, and a *shape* comparison for detecting breaking changes.
src/utils/file.utils.tsReading test data from disk and writing artefacts: JSON, CSV, NDJSON, temporary files, checksums.
src/utils/header.utils.tsHeader parsing: case-insensitive lookup, Set-Cookie, Content-Type, Link, Retry-After, rate-limit counters, and redaction.
src/utils/index.tsBarrel for the utility layer.
src/utils/jsonpath.utils.tsA small, dependency-free JSON path reader supporting property access, array indices (including negative), wildcards and recursive descent.
src/utils/logger.tsA dependency-free structured logger.
src/utils/pagination.utils.tsWalkers for the four pagination conventions — Link header, cursor, offset — plus a normaliser and a defect detector.
src/utils/performance.utils.tsLatency measurement: percentiles, a collector that samples every request, and a sampler for repeated calls.
src/utils/retry.utils.tsPolling and retrying: waitFor, waitUntil, waitUntilGone, retry, withTimeout, sleep and mapWithConcurrency.
src/utils/security.utils.tsSecurity checks that belong in a functional API suite: information disclosure, security headers, CORS, and authorisation matrices.
src/utils/xml.utils.tsXML and SOAP support: parsing, hand-rolled serialisation, path reading, envelope construction and fault extraction.
